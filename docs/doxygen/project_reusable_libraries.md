@page project_reusable_libraries Reusable libraries

GameWIP libraries provide foundation services, engine-facing runtime boundaries, diagnostics, logging, assertions, and validation support. Each library defines its public API, manual, examples, troubleshooting guidance, validation coverage, package boundary, and generated reference.

Use this page as the library index. Use @ref project_structure for dependency direction and ownership rules. Use @ref project_extending when adding or changing a reusable library.
