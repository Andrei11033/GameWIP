@page project_reusable_libraries Reusable libraries

GameWIP reusable libraries provide the project foundation, diagnostics, assertions, logging, and validation support. Each library owns its public API, manual pages, examples, troubleshooting notes, validation coverage, package boundary, and generated reference material.

Use this page as the library index. Use @ref project_structure for dependency direction and ownership rules. Use @ref project_extending when adding or changing a reusable library.
