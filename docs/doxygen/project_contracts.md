@page project_contracts Project contracts and standards

Project contracts define the rules that keep the repository consistent. They are more stable than ordinary workflow notes and should be updated deliberately when ownership, compatibility, backend behavior, documentation policy, versioning, or architectural direction changes.

Use these pages when reviewing whether a change belongs in the project, how it should be documented, and which boundaries it must preserve.
