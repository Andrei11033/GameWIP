# GameWIP v0.0.1 release notes

Milestone: R00 - Bootstrap
Release issue: #11
Next milestone: R01 - Window, Input, and Action Foundation

## Summary

GameWIP `v0.0.1` completes the R00 Bootstrap milestone: the repository can configure, build, validate, document, package, profile, benchmark, version, and prepare guarded releases on the supported Windows development environment. This release covers the reusable foundation libraries, tool libraries, validation systems, setup workflow, and release infrastructure built so far; engine gameplay/runtime implementation remains out of scope for R00 and starts in R01.

The R00 baseline is intentionally still pre-1.0. Its public version is `0.0.1`; untagged development builds continue to show generated `-dev.<build>+g<commit>` identity.
