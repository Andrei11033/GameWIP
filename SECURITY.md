# Security Policy

## Supported Versions

GameWIP is a private, pre-release project. There are no public release lines or supported production versions yet.

Security fixes are handled on the current default branch:

| Version or branch | Supported |
| ----------------- | --------- |
| `master`          | Yes       |
| Public releases   | No        |

## Reporting a Vulnerability

Do not report security vulnerabilities in public issues, discussions, or pull requests.

Report vulnerabilities privately to the repository owner or through GitHub private vulnerability reporting if it is enabled for this repository.

Please include:

- The affected commit, branch, or tag.
- Reproduction steps or a minimal proof of concept.
- Expected and actual impact.
- Relevant logs, crash details, or screenshots.
- Any known workaround.

This project is early-stage and private, so response timing is best effort. Confirmed issues will be fixed on the active development branch before any public release is considered.
