GAME ROADMAP — STEP BY STEP
Project goal:
A realistic sandbox building game with:
- easy building at the base level, like Stormworks
- deeper optional component customization
- Space Engineers-like destructible world/map
- Starbase-like granular destruction feel
- high-rate control/logic simulation where needed

IMPORTANT DEVELOPMENT RULES
1. Physics foundation comes before gameplay features.
2. Simulation architecture comes before content.
3. Destructible structure comes before advanced components.
4. Component damage model comes before lots of components.
5. Components come before logic/control.
6. Logic/control comes before advanced systems.
7. Optimization comes after a real playable prototype exists.
8. Multiplayer comes near the end.
9. Rendering/graphics must exist early enough to debug the game, but the graphics ENGINE does NOT come before physics for this project.
10. Start with debug rendering first, not fancy graphics.

Correct priority:
- minimal rendering first
- then physics core
- then simulation foundation
- then destructible world
Reason:
This game depends much more on simulation, destruction, and control systems than on advanced visuals.
What should be done early is:
- window
- input
- camera
- debug rendering
- simple mesh rendering
That is enough at the start.
Fancy graphics, materials, lighting, effects, and rendering optimization come later.
